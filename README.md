## 🛠️ Built With

- **HTML, CSS, and JavaScript** — one static page, no framework
- **Flight chart UI** — boarding door, pass, route rail, and live instruments
- **On-device copilot** — answers about Davis without sending prompts to a server
- **GitHub radar** — newest public repositories from `@daviesqunyu`

## 🚀 Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/daviesqunyu/DavisPortfolio.git
   ```

2. **Navigate to the project**
   ```bash
   cd DavisPortfolio
   ```

3. **Install dependencies** (if using a local server)
   ```bash
   # No npm install needed - static HTML site
   # Just open index.html in your browser
   ```

4. **Run locally**
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Or just open index.html directly
   ```

5. **Build/Deploy**
   ```bash
   # GitHub Pages automatically deploys from main branch
   # Or use Vercel, Netlify, or any static host
   ```
