# Davis Kunyu - Personal Portfolio

A modern, responsive personal portfolio website showcasing Davis Kunyu's skills, projects, experience, and professional journey as a Lead Software Developer.

## 🌟 Live Demo

**https://davis.dvtechnologies.xyz/

The custom domain is served via **Vercel** (root historically used `book.html`). `index.html` is the canonical home; `vercel.json` rewrites `/` and `/book.html` to it. GitHub Pages also builds from `main` if the DNS CNAME targets GitHub.

## 🛠️ Built With

- **HTML, CSS, and JavaScript** — My Career Path, a multi-page portfolio
- **Opening** — an interactive career reel on the home page; chapters follow in About, Work, Projects, and Contact
- **Chapters** — contents, about, work, projects, craft, marks, and a letter
- **Photographs** — desk, Nairobi dusk, library, lobby, traffic, studio, and paper
- **Google Fonts** — Fraunces, Outfit, and IBM Plex Mono

## 📁 Project Structure

```
DavisPortfolio/

```

## 🚀 Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/daviesqunyu/DavisPortfolio.git
   ```

2. **Navigate to the project**
   ```bash
   cd DavisPortfolio
   ```

3. **Install dependencies** (if using a local server)
   ```bash
   # No npm install needed - static HTML site
   # Just open index.html in your browser
   ```

4. **Run locally**
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Or just open index.html directly
   ```

5. **Build/Deploy**
   ```bash
   # GitHub Pages automatically deploys from main branch
   # Or use Vercel, Netlify, or any static host
   ```
